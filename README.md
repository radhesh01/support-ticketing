# Support Ticketing System

A full-stack support ticket management system with JWT authentication, OTP email verification, and role-based access control.

## Features

- User registration and login
- OTP-based email verification (2FA)
- Create and track support tickets
- Email confirmation on ticket creation
- Admin dashboard to manage all tickets
- Role-based access (user / admin)

## Tech Stack

| Layer    | Tech                             |
| -------- | -------------------------------- |
| Frontend | React, Vite, Tailwind CSS, Axios |
| Backend  | Node.js, Express.js              |
| Database | MongoDB, Mongoose                |
| Auth     | JWT, bcrypt                      |
| Email    | Nodemailer (Gmail SMTP)          |
